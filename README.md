**ResumeForge Pro** is a high-speed, zero-dependency web application engineered for job seekers, academic faculty, corporate executives, and professional document centers. 

It provides **20 ATS-compliant resume templates**, a real-time live preview editor, a zero-flicker dynamic layout fitting engine, and high-resolution 4K vector PDF generation.

---

## Core Capabilities

- **20 Executive Resume Templates:** Instant switching across 20 distinct design formats (Corporate Elite, Harvard Ivy-League, Minimalist, Silicon Valley Tech Lead, Oxford Academic, and Monaco Modern).
- **Real-Time Live Preview Engine:** Sub-millisecond DOM updates during active editing with zero input latency, focus loss, or textarea bouncing.
- **Zero-Flicker 1-Page A4 Fitting Engine:** Intelligent layout measurement scaling font sizes and paddings strictly when content exceeds standard A4 dimensions (295mm / 1115px), ensuring complete single-page space utilization.
- **Indian Biodata & Shopkeeper Integration:** Support for Father's Name, Husband's Name, Mother's Name, Guardian fields, academic marks/CGPA, and traditional biodata standards.
- **Dual PDF Export Pipeline:**
  - **Quick Vector Print (`Ctrl+P`):** Direct browser print layout with color preservation (`-webkit-print-color-adjust: exact`).
  - **4K High Resolution PDF (`Ctrl+Shift+S`):** Clean vector PDF export powered by `html2pdf.js`.
- **Profile Photo Management:** Image upload reader, profile frame preview, reserved background containers, and single-click photo removal.

## Local Setup & Usage

No `npm install` or external build tools required. Clone and open directly in browser:

```bash
# 1. Clone Repository
git clone https://github.com/BeginnerAman/resume-forge-pro.git

# 2. Navigate into project folder
cd resume-forge-pro

# 3. Open in Browser (Windows PowerShell)
Start-Process index.html

# Or start local server
python -m http.server 8080
```
Access the application at `http://localhost:8080`.
