**ResumeForge Pro** is an ultra-fast, zero-dependency, web-based Resume & Biodata Builder engineered specifically for job seekers, executives, academics, and high-speed document printing centers.

It features **20 battle-tested, Applicant Tracking System (ATS) compliant resume templates**, a real-time live preview editor, a zero-flicker dynamic layout fitting engine, and high-resolution 4K vector PDF generation.

---

## ✨ Key Features

- 🏛️ **20 Ultra-Professional Executive Templates:** Switch instantly between 20 distinct design formats (Corporate, Harvard Ivy-League, Minimalist, Tech Lead, Oxford Academic, and Modern Executive).
- ⚡ **Real-Time Live Preview Engine:** Instant DOM updates as you type with zero input latency, focus loss, or textarea bouncing.
- 📐 **Zero-Flicker 1-Page A4 Hysteresis Engine:** Automatically adjusts padding and font scaling only when content exceeds physical A4 dimensions (295mm / 1115px), ensuring 100% full-page space utilization.
- 🇮🇳 **Indian Cyber Cafe & Biodata Friendly:** Native support for Father's Name, Husband's Name, Mother's Name, Guardian details, CTET/CCC qualifications, and traditional biodata requirements.
- 🖨️ **Dual PDF Export Pipeline:**
  - **Quick Print (`Ctrl+P`):** Direct vector printing with exact color preservation (`-webkit-print-color-adjust: exact`).
  - **4K High Resolution PDF (`Ctrl+Shift+S`):** Clean 4K vector PDF generation powered by `html2pdf.js`.
- 🖼️ **AI Profile Photo Management:** Instant photo upload, profile frame preview, reserved image container fallbacks, and single-click photo removal.

## 🚀 Quick Start (Local Setup)

No `npm install` or complex build tools required! Simply clone and launch:

```bash
# 1. Clone the Repository
git clone https://github.com/BeginnerAman/resume-forge-pro.git

# 2. Navigate to directory
cd resume-forge-pro

# 3. Open in Browser
# On Windows PowerShell:
Start-Process index.html

# Or launch local server:
python -m http.server 8080
```
Then open `http://localhost:8080` in your web browser.
